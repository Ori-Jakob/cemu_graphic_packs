Wii U Pro Controller Button Codes

0x00000010 -> A
0x00000040 -> B
0x00000008 -> X
0x00000020 -> Y
0x00000400 -> +
0x00001000 -> -
0x00020000 -> L3 (Left Stick Click)
0x00010000 -> R3 (Right Stick Click)
0x00002000 -> L
0x00000080 -> ZL
0x00000200 -> R
0x00000004 -> ZR
0x00000001 -> D-UP
0x00004000 -> D-DOWN
0x00000002 -> D-LEFT
0x00008000 -> D-RIGHT

Wii U Gamepad Button Codes:

0x00008000 -> A
0x00004000 -> B
0x00002000 -> X
0x00001000 -> Y
0x00000008 -> +
0x00000004 -> -
0x00040000 -> L3 (Left Stick Click)
0x00020000 -> R3 (Right Stick Click)
0x00000020 -> L
0x00000080 -> ZL
0x00000010 -> R
0x00000040 -> ZR
0x00000200 -> D-UP
0x00000100 -> D-DOWN
0x00000800 -> D-LEFT
0x00000400 -> D-RIGHT
